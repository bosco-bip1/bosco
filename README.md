# Max 2023 绑定修型工具

这个仓库提供一个 3ds Max 2023 的 MaxScript：`BindFixTool_Max2023.ms`。

## 功能

- 拾取绑定模型（几何体）
- 在当前姿态生成修型快照
- 自动写入 `Morpher` 指定通道
- 一键把通道值设为 100 便于检查

## 使用步骤

1. 在 3ds Max 2023 打开 `Scripting > Run Script...`，执行 `BindFixTool_Max2023.ms`。
2. 点击 **拾取模型** 选择你的角色网格。
3. 把骨骼摆到有穿插或塌陷的姿态。
4. 选择通道号，点击 **创建修型并写入通道**。
5. 对新建的修型目标做点级编辑（如果勾选了隐藏，可在 Scene Explorer 里取消隐藏）。
6. 回到角色，调节 Morpher 通道值测试修型效果。

## 注意

- Morpher 目标要求与源模型拓扑一致。
- 建议每个问题姿态占用独立通道，便于管理。
