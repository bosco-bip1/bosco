# Max2023 时间工具条

这是一个用于 **3ds Max 2023** 的 MaxScript 工具条脚本：`max2023_time_toolbar.ms`。

## 功能

- 自定义插件槽（3个）
  - 可以绑定你自己的 `.ms` 或 `.mcr` 插件/脚本，一键执行。
- 时间标记与调帧
  - 当前帧快速 +1 / -1。
  - 跳转到指定帧。
  - 标记当前帧、在标记列表中选择并跳转。
- DIY 脚本槽（3个）
  - 预留多个空槽给你放自己的 MaxScript。

## 使用方法

1. 打开 3ds Max 2023。
2. 将 `max2023_time_toolbar.ms` 拖入视口执行（或放入启动脚本目录）。
3. 在工具条中点击：
   - `配置插件槽`：绑定插件脚本。
   - `配置DIY槽`：绑定自定义脚本。
4. 通过“时间调帧”和“时间标记”区域进行动画时间控制。

> 说明：当前版本将配置保存在运行时内存（本次 Max 会话有效）。如果你需要，我可以继续帮你加上配置落盘（INI/JSON）能力。
